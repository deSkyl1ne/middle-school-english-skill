# Practical writing

- Define a realistic `prompt` with purpose, audience, format, length, and required content; keep the situation and language inside the resolved scope.
- Make `rubric` criteria observable, non-overlapping, and point-bearing. The point sum must equal the item score.
- Store a teacher-only `answer.response` or response plan; do not copy a textbook, sample-paper model answer, or long source wording.
- Explain how the response satisfies each criterion in `rationale`; do not turn an illustrative response into a required single wording.
