# Cloze

- Write an original, self-contained `passage` with a coherent information flow and numbered `blanks`.
- Give each blank its own option set in `options`; every blank must have one best fit and a matching `answer.blank_answers` entry.
- Keep options grammatically and semantically comparable, avoid chained clues, and make the rationale explain local and global evidence for each answer.
- Control vocabulary load and score each blank exactly as specified by the blueprint.
