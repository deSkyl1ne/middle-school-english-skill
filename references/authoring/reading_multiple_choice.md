# Reading multiple choice

- Write an original `passage` and one complete `stem` whose answer is directly text-supported.
- Use parallel options and exactly one `answer.option_ids` value. Keep question order reasonably aligned with passage evidence.
- Control out-of-scope vocabulary, provide needed glosses, and never require outside facts or an answer inferred from an unstated assumption.
- Explain the supporting passage cue and why each distractor fails in `rationale`.
- Render the `stem`, any real blank or parenthetical area, and the option set as one contiguous item block. Keep them on one line when they fit; allow only page-width wrapping, never an author-inserted break or continuation label.
- Render the option set once. Do not repeat selection instructions or add per-option notes in the student view.
