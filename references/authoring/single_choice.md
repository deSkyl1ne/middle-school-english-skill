# Single choice

- Write a complete, self-contained `stem` and normally four parallel options; use another count only when the blueprint explicitly requires it.
- Store exactly one option ID in `answer.option_ids`. Options must be mutually exclusive, grammatically parallel, and supported by the stem.
- Build distractors from distinct, diagnosable errors; none may become correct under a reasonable alternate reading. Record why in `rationale`.
- Cite at least one in-scope A/B primary item and keep C/D usage within the common contract.
- Render the `stem`, any real blank or parenthetical area, and the option set as one contiguous item block. Keep them on one line when they fit; allow only page-width wrapping, never an author-inserted break or continuation label.
- Render the option set once. Do not repeat selection instructions or add per-option notes in the student view.
