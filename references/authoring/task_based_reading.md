# Task-based reading

- Write an original `passage` and one or more `tasks`, each with a prompt, response format, and score.
- Define observable evidence requirements for every response. Store one response per `task_id` in `answer.responses` and explain the scoring logic in `rationale`.
- Do not hide outside knowledge, unstated inferences, or vague language in the rubric; keep the task and vocabulary inside the resolved scope.
